# 🤖 Local Windows AI Agent (RAG + GUI)

Продвинутый, полностью **локальный ИИ-ассистент**, интегрированный на низком уровне в операционную систему Windows. Проект разработан на Python и ориентирован на полную независимость от облачных API, интернета, санкций, подписок или типа лицензии вашей ОС (идеально работает на любых кастомных и «пиратских» сборках Windows 10/11).

## 🌟 Ключевые Особенности

*   🔒 **100% Конфиденциальность:** Ваши запросы, код и документы обрабатываются исключительно на вашем ПК через движок **Ollama** и не отправляются на внешние сервера.
*   🧠 **Технология RAG (Knowledge Base):** ИИ обучается на ваших личных файлах (`.txt`, `.md`, `.py`, `.log`). Достаточно сбросить документы в папку, и ассистент будет использовать их как базу знаний при ответах.
*   ⚡ **Продвинутый Системный Маневр (Screen Capture):** Выделите любой текст или код на экране в любой программе (браузер, IDE, игра) и нажмите `Ctrl + Alt + X` — ИИ мгновенно перехватит его из оперативной памяти, откроет чат и выдаст анализ/исправление ошибок.
*   🚀 **Асинхронный Стриминг (UI):** Графический интерфейс на базе **CustomTkinter** работает в многопоточном режиме. Тяжелые вычисления ИИ вынесены в фон, а текст выводится посимвольно в реальном времени без «зависания» окна.
*   🥷 **Скрытая работа в фоне:** Скрипт запускается без черных окон консоли и незаметно ожидает команд пользователя по глобальным хоткеям.

---

## 🛠 Технологический Стек

*   **Core Engine:** Python 3.11+ / Ollama API
*   **LLM Model:** Llama 3.2 (3B) / Gemma 2 (2B/9B)
*   **Vector Database:** ChromaDB (Persistent Local Client)
*   **Embeddings:** Sentence-Transformers (`all-MiniLM-L6-v2` локально)
*   **UI Framework:** CustomTkinter (Многопоточный рендеринг, Dark Theme)
*   **OS Automation:** Keyboard Hooks & Pyperclip Buffering

## 🚀 Быстрый Старт и Развертывание

### Шаг 1. Подготовка ИИ-движка (Ollama)
1. Скачайте и установите **Ollama** с официального сайта: [ollama.com](https://ollama.com).
2. Запустите командную строку Windows (CMD) и скачайте базовую модель (требуется ~2.5 ГБ VRAM/ОЗУ):
   ```bash
   ollama pull llama3.2:3b
   ```
3. Убедитесь, что Ollama работает в трее, или проверьте статус в браузере по адресу `http://localhost:11434`.

### Шаг 2. Клонирование и настройка окружения
Откройте терминал в папке проекта на вашем ПК:
```bash
# Создаем изолированное виртуальное окружение
python -m venv venv

# Активируем окружение в Windows
call venv\Scripts\activate

# Устанавливаем все необходимые библиотеки
pip install -r requirements.txt
```

### Шаг 3. Обучение ИИ на ваших документах (Опционально)
1. Поместите ваши текстовые файлы, инструкции, скрипты или шпаргалки в папку `data/documents/` (если папки нет, создайте её).
2. Запустите синхронизацию векторной базы:
   ```bash
   python sync_rag.py
   ```
   *База данных пересчитает эмбеддинги, фрагментирует тексты и сохранит их локально.*

### Шаг 4. Запуск фоновой службы
Для скрытого запуска ИИ-агента просто дважды кликните по файлу **`run.bat`**. 
Процесс запустится через `pythonw.exe`, что предотвратит появление консольных окон. Приложение готово к работе в фоновом режиме.

## 🕹 Инструкция по Использованию

Система управляется из любого места Windows с помощью глобальных горячих клавиш:

1.  **`Ctrl + Alt + Z`** — Вызвать окно чата поверх всех окон (или скрыть его обратно в фон). Диалог сохраняет контекст вашей текущей беседы.
2.  **`Ctrl + Alt + X` (Главный Маневр)** — Выделите мышкой любой непонятный кусок кода в вашей IDE, ошибку в терминале или текст в браузере и нажмите комбинацию. Окно чата мгновенно развернется, и ИИ выдаст подробный разбор выделенного фрагмента.

## 🔧 Кастомизация (`config/settings.json`)

Вы можете гибко настраивать поведение системы в файле конфигурации без изменения исходного кода Python:
*   `model_name`: Вы можете заменить `llama3.2:3b` на более тяжелые модели, например `gemma2:9b` или `llama3.1:8b`, если позволяет ваша видеокарта (рекомендуется от 12 ГБ VRAM).
*   `hotkeys`: Измените сочетания клавиш, если они конфликтуют с вашими рабочими программами.
*   `rag.chunk_size`: Размер фрагментов текста для анализа документов (в символах).
