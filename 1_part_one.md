## 1. Концепция и Архитектура Системы
Наш ИИ-ассистент проектируется как локальный агент, работающий в фоновом режиме Windows. Архитектура построена на модульном принципе:

[ Пользовательский ввод: Горячие клавиши / Буфер обмена / GUI ]
                       │
                       ▼
         [ Главное ядро (Core Engine) ] ◄──► [ Локальное хранилище истории ]
                       │
        ┌──────────────┴──────────────┐
        ▼                             ▼
 [ Модуль RAG (ChromaDB) ]   [ Локальный LLM-сервер (Ollama) ]
        │                             │
        ▼                             ▼
(Поиск в личных документах)   (Генерация текста / Кода / Логика)


   1. Интерфейсный слой (UI/UX): Асинхронный перехватчик системных событий. Считывает выделенный пользователем текст напрямую из оперативной памяти (буфер обмена) или вызывает графическое окно.
   2. Оркестратор (Core Engine): Python-приложение, управляющее потоками данных. Оно принимает запрос, решает, нужен ли поиск по локальным документам, формирует расширенный промпт (Prompt Engineering) и управляет контекстом (памятью).
   3. Локальный инференс (LLM Engine): Движок Ollama, изолированный от внешней сети. Работает напрямую с тензорными ядрами видеокарты через CUDA.
   4. База знаний (RAG): Векторная база данных для хранения и семантического поиска по пользовательским файлам (TXT, PDF, код).

## 2. Полный технологический стек (Stack Choice)
Мы используем только стабильные, поддерживаемые open-source инструменты с открытой лицензией (MIT/Apache 2.0):

* Базовый язык: Python 3.11.x или 3.12.x (64-bit). Выбирается из-за нативной поддержки библиотек ИИ и глубокой интеграции с API Windows.
* Движок нейросети: Ollama (локальный оркестратор моделей). Оптимален, так как автоматически управляет квантованием, VRAM/RAM и поддерживает потоковую передачу данных (streaming API).
* Базовая LLM модель: Llama 3.2 (3B) (для систем с ≤ 8 ГБ VRAM) или Gemma 2 (9B) / Llama 3.1 (8B) (для систем с ≥ 12 ГБ VRAM).
* Векторная база данных (RAG): ChromaDB (локальная, встраиваемая). Не требует поднятия тяжелых серверов типа Docker/PostgreSQL, работает из папки проекта.
* Эмбеддинги (векторизация текста): sentence-transformers/all-MiniLM-L6-v2 через HuggingFace (работает локально).
* Интерфейс автоматизации Windows: keyboard (низкоуровневый перехват клавиш) + pyperclip (работа со скрапингом буфера обмена).
* Графический интерфейс: CustomTkinter (современная UI-обертка над стандартным Tkinter с поддержкой темной темы и аппаратного сглаживания).

## 3. Эталонная структура репозитория на GitHub
Создайте на вашем компьютере пустую папку (например, local-ai-agent). Внутри нее структура должна выглядеть строго следующим образом. Это стандарт для чистого, профессионального кода.

local-ai-agent/
│
├── .gitignore               # Исключение кэша, виртуального окружения и векторов базы
├── README.md                # Главный гайд (который мы сейчас пишем)
├── requirements.txt         # Список зависимостей Python с жестко зафиксированными версиями
├── run.bat                  # Скрипт для скрытого запуска ассистента в один клик
│
├── config/                  # Конфигурационные файлы
│   └── settings.json        # Настройки горячих клавиш, путей и параметров модели
│
├── core/                    # Логическое ядро системы
│   ├── __init__.py
│   ├── agent.py             # Главный оркестратор (управление логикой)
│   ├── llm_client.py        # Интерфейс взаимодействия с Ollama API
│   └── memory.py            # Управление историей диалога (буфер контекста)
│
├── rag/                     # Модуль работы с локальными документами
│   ├── __init__.py
│   ├── vector_store.py      # Инициализация и поиск в ChromaDB
│   └── document_parser.py   # Скрипт для индексации локальных папок
│
├── ui/                      # Графический интерфейс пользователя
│   ├── __init__.py
│   └── chat_window.py       # Окно чата на CustomTkinter
│
└── data/                    # Локальные данные (Добавлена в .gitignore)
    ├── db/                  # Файлы векторной базы данных ChromaDB
    └── documents/           # Сюда вы будете складывать свои документы для ИИ
